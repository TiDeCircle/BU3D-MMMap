# BU3D-MMMap · แผนที่เสมือน 3 มิติ มหาวิทยาลัยกรุงเทพ วิทยาเขตรังสิต

เว็บแผนที่ 3 มิติแบบ interactive ของวิทยาเขตรังสิต สร้างด้วย [Three.js](https://threejs.org/) เปิดในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม

## ความสามารถ

- โมเดล 3 มิติของอาคาร 38 จุด แบ่งตาม 4 โซน (A–D) ใช้หมายเลขเดียวกับแผนผังทางการของมหาวิทยาลัย
- ตึกเพชร (A3) หันหน้าออกถนนพหลโยธิน มีสระน้ำและป้าย BANGKOK UNIVERSITY ด้านหน้า
- หอพักนักศึกษาท้ายมหาวิทยาลัย บึงน้ำ สนามฟุตบอลและลู่วิ่ง สนามเทนนิส คลอง ถนน ลานจอดรถ ต้นไม้ และรถบนถนนพหลโยธิน
- ค้นหาอาคารด้วยชื่อไทย ชื่ออังกฤษ รหัสอาคาร หรือหมายเลข และกรองตามโซนหรือประเภท
- คลิกอาคารเพื่อดูรายละเอียดและให้กล้องบินไปที่อาคารนั้น
- โหมดเดินชม (มุมมองบุคคลที่หนึ่ง): W A S D เพื่อเดิน, Shift เพื่อวิ่ง, ลากเมาส์เพื่อมองรอบ ๆ บนมือถือมีปุ่มลูกศรให้กด
- สลับกลางวันและกลางคืน (กลางคืนไฟในหน้าต่างและเสาไฟจะสว่าง)
- ผังย่อแบบทิศเหนืออยู่ด้านบน แตะที่ผังเพื่อไปยังจุดนั้น
- ส่งลิงก์ไปยังอาคารได้ เช่น `index.html#C6` จะเปิดมาที่หอสมุด
- รองรับจอมือถือ และใช้สีตามโหมดสว่าง/มืดของเครื่อง

## วิธีเปิดใช้งาน

เปิดไฟล์ผ่านเว็บเซิร์ฟเวอร์ (เพราะใช้ ES modules ซึ่งเปิดจาก `file://` ตรง ๆ ไม่ได้)

```bash
python3 -m http.server 8000
```

แล้วเข้า http://localhost:8000

หรือเปิดใช้ GitHub Pages ของ repo นี้ (Settings → Pages → Deploy from branch) ก็ใช้งานได้เลย เพราะไม่มีขั้นตอน build

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บและแผงควบคุม |
| `css/style.css` | สไตล์ของหน้าเว็บ |
| `js/campus-data.js` | **ข้อมูลวิทยาเขตทั้งหมด** อาคาร ถนน แหล่งน้ำ สนามกีฬา และมุมกล้อง |
| `js/main.js` | ตัวสร้างฉาก 3 มิติ การควบคุม และ UI |
| `ref/` | ภาพอ้างอิง (ภาพโดรน, Street View) ที่ใช้เทียบตอนปั้นโมเดล ดูรายละเอียดใน `ref/README.md` |

## การแก้ไขข้อมูลอาคาร

แก้ที่ `js/campus-data.js` ไฟล์เดียว หน่วยเป็นเมตร

- แกน `x`: ค่าน้อย = ทิศตะวันออก (ทางเข้าติดถนนพหลโยธิน), ค่ามาก = ทิศตะวันตก (ท้ายมหาวิทยาลัย)
- แกน `z`: ค่าบวก = ทิศเหนือ
- `w`, `d`, `h` = ความกว้าง (แกน x), ความลึก (แกน z) และความสูงของอาคาร
- อาคารที่ซับซ้อนใช้ `shape: 'composite'` แล้วกำหนดชิ้นส่วนใน `parts` (`box`, `glass`, `curtain`, `solid`, `hull`)
- `shape` = รูปทรง: `box`, `composite` (กำหนดจุดรูปทรงเหลี่ยมเอง ใช้กับตึกเพชร), `tower`, `round`, `barrel`, `gable`, `pavilion`, `thai`, `shrine`, `dorm`, `none`

## ที่มาของข้อมูลและข้อจำกัด

- ชื่อ หมายเลข และโซนของอาคาร 1–37 มาจากแผนผังทางการของมหาวิทยาลัย
- ทิศทาง ขอบเขตวิทยาเขต โซน D และหอพักนักศึกษา ปรับตามภาพถ่ายดาวเทียมจาก Google Maps
- รูปลักษณ์ของตึกเพชรอ้างอิงจากภาพ Google Street View หน้ามหาวิทยาลัย
- ตำแหน่ง ขนาด ความสูง และรูปทรงของอาคารเป็นค่าประมาณสำหรับการจำลอง ไม่ใช่แบบสำรวจจริง
