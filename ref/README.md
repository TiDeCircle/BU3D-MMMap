# ภาพอ้างอิง

ภาพที่ใช้เทียบตอนปั้นโมเดล ลิขสิทธิ์เป็นของเจ้าของภาพ (Google และมหาวิทยาลัยกรุงเทพ) เก็บไว้ใช้อ้างอิงในโปรเจกต์นี้เท่านั้น

| ไฟล์ | ที่มา | ใช้อ้างอิงเรื่อง |
| --- | --- | --- |
| `streetview-diamond-2013.webp` | Google Street View (พ.ย. 2013) บนถนนพหลโยธิน | หน้าตาของ A1, A2 และ A3 จากระดับถนน, สระน้ำและสนามหญ้าด้านหน้า |
| `drone-front-from-east-1.webp` | ภาพโดรนจากเว็บ Campus Visit มองจากถนนพหลโยธินไปทางทิศตะวันตก | กลุ่มตึกเพชร, สระสามเหลี่ยม, ทางเดิน, เสาธง, อาคาร A8 |
| `drone-front-from-east-2.webp` | ภาพโดรนจากเว็บ Campus Visit มุมเดียวกัน ระยะใกล้ขึ้น | รายละเอียดผิวอาคาร A1, A2 และผนังม่านกระจกของ A3 |
| `drone-zone-a-pond-looking-east.webp` | ภาพโดรนจากเว็บ Campus Visit มองไปทางทิศตะวันออก | ด้านหลัง A3, สระน้ำยาวกลางโซน A, เรือนไทย, แถวอาคารฝั่งเหนือและใต้ |
| `drone-zone-a-south-row-looking-south.webp` | ภาพโดรนจากเว็บ Campus Visit มองไปทางทิศใต้ | หอคอย A5 และอาคารยาวกรอบหน้าต่างสีแดงฝั่งใต้ |
| `drone-zone-a-north-row-looking-north.webp` | ภาพโดรนจากเว็บ Campus Visit มองไปทางทิศเหนือ | อาคาร A7 หลังคาโซลาร์, ลานจอดรถและถนนด้านทิศเหนือ |
| `drone-zone-a-looking-west.webp` | ภาพโดรนจากเว็บ Campus Visit มองไปทางทิศตะวันตก | ภาพรวมโซน A ต่อเนื่องไปโซน B, โรงอาหาร, สนามกีฬา, ถนนรอบนอก |
| `satellite-zone-a-roads.webp` | Google Maps ดาวเทียมมุมบน ทิศเหนือขึ้น เส้นเหลืองวาดทับเป็นแนวถนน | **ใช้วางผังโซน A** ทั้งถนน อาคาร สระน้ำ (มาตราส่วนราว 0.4 ม./พิกเซล อ้างอิงจากอาคาร A3) |
| `satellite-a1-a3-south-parking.webp` | Google Maps ดาวเทียมมุมบน กรอบสีน้ำเงินคือลานจอดรถ | ลานจอดรถริมถนนด้านใต้ของกลุ่มตึกเพชร, ถนนวงรอบ A3 |
| `drone-front-south-parking.webp` | ภาพโดรนจากเว็บ Campus Visit วงสีน้ำเงินคือลานจอดรถ | ลานจอดรถและแนวต้นไม้ทางใต้ของ A2 |
| `feedback-model-no-parking-behind-a4-a6.webp` | ภาพหน้าจอโมเดลเวอร์ชันก่อนหน้า วงสีแดงคือจุดที่ผิด | หลังอาคาร A4–A6 ไม่มีลานจอดรถ |
| `feedback-no-south-side-street.webp` | ภาพหน้าจอโมเดล วงสีน้ำเงินคือถนนที่ไม่มีจริง | ไม่มีซอยเลียบด้านใต้หน้าหอพักหญิง |
| `feedback-no-south-road-zones-b-d.png` | ภาพหน้าจอโมเดล วงสีน้ำเงินคือถนนที่ไม่มีจริง | ไม่มีถนนเลียบขอบด้านใต้ตลอดโซน B–D |

## ภาพที่ใช้แล้วแต่ยังไม่ได้อยู่ในโฟลเดอร์นี้

ภาพเหล่านี้ถูกส่งมาในแชตโดยไม่มีไฟล์แนบ จึงยังไม่ได้บันทึกไว้ ถ้ามีไฟล์ให้เพิ่มเข้ามาในโฟลเดอร์นี้ได้เลย

- แผนผังทางการของมหาวิทยาลัย (โซน A–D อาคารหมายเลข 1–37)
- ภาพถ่ายดาวเทียม Google Maps ทั้งวิทยาเขต พร้อมเส้นขอบเขตสีแดง
- ภาพ Google Street View หน้ามหาวิทยาลัย (เม.ย. 2025) 2 ภาพ
- ภาพ Google Street View ถนนทางเข้าข้างอาคาร A8 และทางเลี้ยวเข้าลานจอดรถ (ก.พ. 2022) 5 ภาพ
- ภาพถ่ายดาวเทียม Google Maps ของอาคาร A1, A2, A3 มุมบน
